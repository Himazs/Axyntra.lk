## Google setup (account owner actions)
1. Open https://search.google.com/search-console and add the axyntra.lk domain property. Verify ownership using the DNS record Google provides. The included verification file may support an existing URL-prefix property; do not assume the property is already verified.
2. Submit https://axyntra.lk/sitemap.xml after deployment and inspect the homepage and founder URL. Request indexing where appropriate; indexing and display are not guaranteed.
3. Ensure hosting redirects www and HTTP versions to the preferred HTTPS hostname used in canonicals. This requires host-specific configuration; the HTML cannot enforce it.
4. Test structured data using https://search.google.com/test/rich-results and inspect rendered URLs through Search Console. General Person/Organization data does not guarantee a rich result or knowledge panel.
5. If customers visit a genuine eligible location or you visit clients in person, review Google Business Profile eligibility at https://support.google.com/business/answer/7039811 before creating a profile. Online-only businesses are ineligible. Do not use a false address or change the business name to include keywords.
6. Ask real clients for honest reviews without incentives or requests for positive-only feedback.
